# almoxarifado
Sistema de almoxarifado para o SENAI feito pela turma TerceTROIA

## Objetivos do projeto:
Este sistema foi desenvolvido na disciplina de Implantação de Sistemas SENAI. O objetivo é controlar o estoque de materiais de TI e escritório da instituição, registrando entradas, saídas gerando alertas de estoque baixo.
