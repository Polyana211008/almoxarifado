# Requisitos do Sistema de Almoxarifado

## Requisitos Funcionais
1. Coletar dados do usuario
2. Verificar o estoque
3. Saber quem fez movimentos dos produtos

## Requisitos Não Funcionais 
1. Ser acessível aos celulares, computadores e tablets
2. Não ter cor
3. Senha fraca 

# Regras de Negócio
1. Consistência
2. Não permitir saldo negativo
3. Rastreabilidade
